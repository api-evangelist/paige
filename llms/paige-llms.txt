# Paige

> Paige (Paige AI, Inc.) is a New York City computational-pathology company founded in 2017 out of
> Memorial Sloan Kettering. It was the first company to receive FDA authorization for a clinical AI
> application in digital pathology (Paige Prostate, De Novo, 2021) and holds FDA 510(k) clearance for
> the FullFocus whole-slide-image viewer plus 12 CE-IVD and UKCA marks. Paige was acquired by
> Tempus AI in September 2025.

This llms.txt was generated by API Evangelist from public sources on 2026-08-04. Paige does not publish
an llms.txt of its own (https://www.paige.ai/llms.txt returns 404).

## API surface

Paige markets **UnifAI** — an SDK plus a set of APIs for vendor-neutral integration of AI applications
into laboratory digital-pathology workflows, and the mechanism behind the Paige AppLab marketplace.
**That developer surface is not publicly documented.** As of 2026-08-04:

- `docs.paige.ai` is CNAMEd to ReadMe.io but returns Cloudflare error 1014 for every path.
- `api.paige.ai`, `developer.paige.ai`, `platform.paige.ai` and `unifai.paige.ai` do not resolve.
- `app.paige.ai` is the customer application login; it is a single-page app whose catch-all route
  answers 200 with an HTML shell for every path, including `/openapi.json` and `/graphql`.

No OpenAPI, AsyncAPI, GraphQL SDL, MCP manifest or A2A agent card is publicly retrievable. Integration
access goes through a laboratory customer relationship — https://www.paige.ai/request-a-trial

## Open-source and open-weights

- [paige-ml-sdk](https://github.com/Paige-AI/paige-ml-sdk): Python SDK + CLI (`python -m paige.ml_sdk`)
  for training supervised computational-pathology models over tile-level embeddings. Non-commercial
  academic research license. Not on PyPI — install from source.
- [philips-isyntax-rs](https://github.com/Paige-AI/philips-isyntax-rs): Rust bindings for the Philips
  Pathology SDK (iSyntax WSI format).
- [cdh1-cancer-res](https://github.com/Paige-AI/cdh1-cancer-res): model source for detecting CDH1
  bi-allelic mutations in breast pathology samples.
- [omniscreen-eval-results](https://github.com/Paige-AI/omniscreen-eval-results)
- Foundation models on Hugging Face ([paige-ai](https://huggingface.co/paige-ai)), CC-BY-NC-ND-4.0:
  [Virchow](https://huggingface.co/paige-ai/Virchow),
  [Virchow2](https://huggingface.co/paige-ai/Virchow2),
  [Prism](https://huggingface.co/paige-ai/Prism),
  [Prism2](https://huggingface.co/paige-ai/Prism2),
  [Prism2-survival](https://huggingface.co/paige-ai/Prism2-survival)
